# AMOLED 用量面板界面规范

本规范定义 480×480 AMOLED 用量面板的颜色、排版与状态呈现。

本规范约束基于 **LVGL** 的界面实现；当前采用该技术栈的是 480×480 AMOLED 目标Waveshare ESP32-S3-Touch-AMOLED-2.16 与由其移植的 ESP-Mosaico。ePaper 3.97 使用独立绘制与刷新策略，见其目标 README。参考实现为 `firmware/targets/esp32_s3_touch_amoled_216/main/display_ui.cpp`。

M5StickS3（135×240）使用 M5Unified/LovyanGFX，配色、阈值与排版以其 `display_ui.cpp` 为准，不适用本文。新增 LVGL 目标需按实际屏幕重新确定尺寸。

## 1. 色板

| Token | Hex | 用途 |
|---|---|---|
| bg | `#0A0C10` | 屏幕背景 |
| panel | `#171B22` | 卡片/面板底（需在 AMOLED 纯黑背景上保持可辨边界）|
| border | `#272C35` | 卡片描边；分隔线用 `#1D2128` |
| track | `#252A33` | 进度条槽 |
| text | `#F2F4F7` | 主文字、默认数值、默认进度条填充 |
| muted | `#8B93A1` | 次级标签（SHORT/WEEK、窗口名） |
| dim | `#565D68` | 三级信息（时间戳、辅助说明） |
| good | `#3ECF8E` | 仅用于连接状态 LINKED |
| warn | `#F5B84C` | 用量 ≥80%、配对中状态 |
| bad | `#F26D6D` | 用量 ≥95% |

**单色系原则**：默认一切都是灰阶（text / muted / dim）。彩色只在两处出现——连接状态点，以及 ≥80% 的百分比数值与其进度条。标题、强调、选中态一律不用彩色。

**选中态**用反色而非彩色：选中项 `bg:text(#F2F4F7)` + `fg:bg(#0A0C10)`，未选中 `bg:panel` + `fg:muted`。

## 2. 状态色规则（唯一判定逻辑）

```
percent >= 95  -> bad   #F26D6D
percent >= 80  -> warn  #F5B84C
otherwise      -> text  #F2F4F7
无数据          -> dim   #565D68
```
适用目标的所有页面共用此规则。

总览卡片右上角正常显示短周期重置时间，异常时在同一位置显示数据状态。详情页右上角正常显示最后有效样本的年龄，异常时显示数据状态；年龄以源采样时间计算，不以 BLE 收包时间计算。仅蓝牙断开或从未取得有效数据时使用 dim 色和异常状态文字。连接正常且已有有效数据时，取数失败和样本年龄均不改变数值、进度条或配色；继续显示最后有效样本，收到新数据后更新。刷新失败不增加提示，网络、登录和账号问题由 CodexBar 处理。部分样本未提供的周期显示 `--`，不混用更早周期的数值。百分比统一表示已用；周期标签保持 SHORT / WEEK，不逐行重复 USED。

屏保的条形、数字和亮度等级对应同一已报告周期，选择已用比例较高的周期，并在数字旁标出 SHORT / WEEK。两个服务均从未取得有效数据时显示 DATA UNAVAILABLE；蓝牙断开时显示 OFFLINE。连接正常时，屏保保留各服务最后有效样本，不因刷新失败或样本年龄清空。

## 3. 字号阶梯

Waveshare（480×480）：68 / 30 / 26 / 20 / 16 / 15 / 14 / 13

Display 级 **120**，仅用于屏保态的时钟数字，不得用于其他任何元素。

**远距离可读优先**：该屏幕的典型使用距离为 0.5–1 m，因此字号需要明显大于桌面 UI。详情页百分比 **68px**，总览页百分比 **30px**，任何标签不得小于 13px。小屏目标的字号阶梯待其接入本设计语言时另行定义。

用途固定：
- 大数值（详情页百分比）= 最大号，700
- 页面/卡片标题 = 次大号，600
- 标签（SHORT/WEEK）= 小号，muted，`letter-spacing: 0.05–0.06em`
- 时间戳/辅助 = 最小号，dim

**全大写 + 字距**：所有英文标签、状态、按钮文字一律大写并带 `letter-spacing`，中文不加字距。

## 4. 间距与网格

界面文案一律英文（大写 + 字距）。

Waveshare：屏幕边距 24px；卡片宽 432px；卡片内边距 20–22px；卡片圆角 16px；卡片间距 14px；顶部标题栏高 50px 后接 1px 分隔线；底部导航高 34px，起始于 y=436；内容区与导航之间不额外设置分隔线。

**圆角按屏幕物理尺寸缩放**（方屏 16px；小屏数值待有设备接入本设计语言时确定），不同设备不单独定义无关的圆角尺度。

## 5. 组件规格

- **卡片**：`panel` 底 + 1px `border` 描边 + 对应圆角。
- **进度条**：槽 `track`，填充色 = 状态色规则的结果；方屏高 **12px（总览）/ 16px（详情）**；圆角为高度的一半。实机验证表明，更细的进度条不利于辨识。填充变化走 180ms 缓出动画（读数从 12% 跳到 35% 时补间过去，不硬切）；填充色仍随新数值瞬时切换。数据置空复位为 0、以及 OTA 进度，都不用动画。
- **重置时间**：是关键信息，不是脚注。详情页 16px `#C7CCD4` 600，靠右与窗口标签同行；总览卡片头部右侧以 SHORT RESET 标明短周期归属，14px `#C7CCD4`；周周期重置时间在详情页显示。重置时刻已过且尚无新样本时显示 `RESET WAIT`，不表示服务已确认额度恢复。
- **配对态**：整块内容区遮罩（顶部分隔线到底部导航之间铺满 `bg`），中间居中一张卡片显示配对码。不使用悬浮卡片覆盖数据内容。
- **底部导航**：方屏为**纯文字标签 + 下划线指示**，不用色块、不用卡片底。34px 高的三等分标签条，标签 13px 600 大写、字距 0.06em；未选中 `#565D68`，选中 `#C7CCD4` 并在标签下方 7px 处加一条 26×2px（圆角 1px）`#C7CCD4` 短横。导航是次要信息，任何情况下都不能成为屏幕上最亮的元素。**下划线是三个标签共用的同一条**，翻页时以 180ms 缓出横向滑到新标签下方，而不是在旧位置熄灭、新位置点亮；页面本身仍是硬切换。
- **连接状态**：右上角一个 8px 状态色圆点 + 14px `#C7CCD4` 文字。不显示 `SECURE` 之类无操作价值的标签。
- **电池**：连接状态右侧，30×14 描边（1px `#565D68`）+ 2px 正极点，内含 4 段。**分级显示，不显示百分比**：FULL=4 段、HIGH=3 段、MID=2 段、LOW=1 段、无数据=0 段；点亮色 `#C7CCD4`，熄灭段 `#2C313B`；仅 LOW 时点亮段转 `#F5B84C`。**充电**：外框左侧 gap 5px 有 7×12 闪电槽，**始终占位**（不充电时留空，绝不收起，否则插拔 USB 会让 `LINKED` 平移）；充电时填 `#C7CCD4`，段数照常反映电量，不做动画；充电时 LOW 不再变黄（外部供电已接入，此时低电量告警不再提供操作价值），屏保 `LOW` 角标同时撤掉。USB 只是供电，不改变 `LINKED`，界面不出现 `USB` 标签。
- **时间**：顶栏左侧，22px 700，`text` 色，24 小时制不显示秒。页面归属由底部导航指示，无需重复标题。硬件无温湿度传感器，界面不出现环境信息。
- **屏保态（SCREENSAVER）**：空闲 5 分钟后进入，触摸屏幕或晃动（IMU）唤醒，回到进入前的页面。规则是**整体降一级**——时钟 `muted #8B93A1`（120px，居中 top 158）、日期一行 20px `dim`、顶栏与底部导航全部隐藏、卡片去掉 panel 底与描边（纯 `bg`，AMOLED 省电）。屏幕上不得出现 `text` 级亮度。底部 13px `#2C313B` 提示 `TAP OR SHAKE TO WAKE`，进入 3 秒后淡出。仅电池 LOW 时右上角显示降亮的 `LOW` + 电池图标（`#8A6A2E`），其余状态一概不显示。防烧屏：整块内容每 60 秒随机位移 ±10px。

## 6. 本地显示设置

微雪设备长按触屏约 0.8 秒进入全屏设置页。亮度范围 1–100%，调整时预览；自动进入时钟支持 OFF、1、5、10、30 分钟。SAVE 写入 NVS，CANCEL 恢复已保存值；首次启动使用 menuconfig 默认值。OFF 不影响主动切换时钟。设置页打开时保持唤醒，配对和 OTA 优先于设置并撤销未保存预览。

设置页采用 24px 边距的行式布局，两项设置以 1px `#1D2128` 分隔线分组，不增加卡片底色与描边。顶栏左侧显示 DISPLAY，右侧复用连接状态与电池；LINKED 保持绿色。设置操作优先保证近距离触控，不要求全部读数使用远距离展示字号。

- **亮度设置行**：复用现有 48px 数值字体；右侧加减按钮为 80×80px，间隔 8px。仅通过按钮调整，不显示不可操作的滑条。到达 1% 或 100% 时禁用对应按钮，边界不循环。
- **有限选项选择**：AUTO CLOCK 下方标明 AFTER IDLE / MIN；OFF、1、5、10、30 五项为 80×64px，间隔 8px，一次点击选定。只有当前选项反色，不累计填充；OFF 不拼接 MIN。保留非标准 menuconfig 默认时长，未匹配预设时显示当前秒数，直到用户主动选择预设。
- **操作状态**：16px 圆角，可见边界与点击区域一致。选中项及可用 SAVE 使用 text 底、bg 字；未选项和 CANCEL 使用 panel 底、muted 字。按下时背景和边框产生灰阶反馈；禁用控件使用 panel 底、dim 字，不响应点击。不使用主题阴影或过渡。
- **保存与取消**：底部按钮均为 206×64px，间隔 20px。未修改时禁用 SAVE，修改后启用；CANCEL 始终可用。保存成功后退出，失败时保留页面和预览，在按钮上方显示 SAVE FAILED - TRY AGAIN 并允许重试。不常驻显示持久化实现说明。

实机验证需覆盖最低亮度恢复操作、桌面支架姿态下的按钮命中、OFF、未修改／已修改以及保存失败状态；像素尺寸与桌面预览不能替代触控和 AMOLED 可读性验收。

## 7. 其他限制

- 不使用渐变、阴影堆叠或 emoji。
- 数据缺失显示 `--` 与 dim 色。
- 用量只显示百分比和重置时间，不显示 token 绝对用量。
