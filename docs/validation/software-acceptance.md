# 测试与发布验收

软件测试验证解析、状态机和平台适配边界；硬件测试验证真实连接、显示、输入和升级行为。项目已有实机覆盖见[验证范围](../verification.md)。

## 软件检查

从仓库根目录运行：

```sh
python -m pip install -e ./bridge
python -m unittest discover -s bridge/tests -v
npm ci --prefix web --ignore-scripts
npm run check --prefix web
npm run build --prefix web
npm test --prefix web
```

仅改文档时检查链接与 `git diff --check`，无需构建。固件按[固件说明](../../firmware/README.md)和目标注册表选择 SDK，测试镜像编译与芯片执行分开记录。平台专属主机测试可跳过；模拟 BLE 与浏览器引擎不代表实机通过。

## 硬件工具

- `tools/run_ota_validation.py`：对现有安全绑定执行本地镜像 OTA。先停止占用该设备的 Bridge，核对目标、版本和镜像，再在设备端确认；该工具不验证生产安装包的下载与确认界面。
- `tools/measure_ota_ble.py`：已配对设备的短负载传输测量，不能替代完整固件升级。
- `tools/capture_panel_serial.py` 与 `tools/summarize_panel_performance.py`：采集并汇总显示探针数据。
- [墨水屏局刷 demo](../../tools/ws397/PARTIAL_DEMOS.md)：区分窗口寻址、差分、旋转与设置页显示问题。

日志和帧缓冲导出可放入已忽略的 `.test-artifacts/`。分享前删除设备地址、绑定、账号信息和真实用量；只保留复现必要的合成数据或脱敏片段。

## 发布候选验收清单

固定源码提交和配置，记录平台、设备型号、Bridge/固件/manifest 摘要以及操作结果。重新构建的同版本文件不能沿用其他字节的验收结论。

- [ ] 协议：合法最小设备、未知型号与可选能力；不支持的版本、缺失 `usage.v1`、重复键、非法 UTF-8、数字边界和超长帧均正确处理。
- [ ] 多设备：新增、重连、同名设备、改名、移除、同地址重新添加；旧回调失效，单设备失败不影响其他设备。
- [ ] OTA：正常升级、链路中断、损坏摘要、供电中断、失败后重试和启动失败回滚；每个维护目标及桌面平台分别验证。
- [ ] 更新生命周期：下载、桌面确认和重启期间退出或移除设备，任务清理完成；目标或产物变化后不继续安装，升级期间重新配对应被拒绝。
- [ ] 电源：外部供电、电池、无效读数与 40% 门槛边界，插电后恢复行为；启动有效状态无需主机连接也能完成本地确认。
- [ ] 界面与配置：显示、输入、方向、亮度、广播名、唤醒与屏保超时；墨水屏观察不同方向、温度及多日残影。
- [ ] 桌面：Windows/macOS 干净环境的安装、蓝牙授权、启动、自启、菜单、更新与卸载。
- [ ] Web：每个型号的选择、确认、真实写入、复位、设备启动与用量同步；取消、下载失败、端口占用和写入中断后的恢复。
- [ ] 擦除：在允许清除配置的测试设备上核对 NVS 擦除、主机旧配对清理和重新连接。

写入达到 100% 不等于设备已正常启动；串口完成刷新不等于屏幕没有残影。无法执行的项目明确标为未验证。
