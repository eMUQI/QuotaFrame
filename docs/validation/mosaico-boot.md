# Mosaico 开机耗时

用户反馈开机后白屏闪一下，约 10 秒才出现连接、数据和旋转响应。以下时间取自 UART0 启动日志的时间戳（上电起算，单位 ms），调整前后各一次冷启动，均为手势固件、相机开启、Bridge 已配对并在运行。单次测量不代表分布；Bridge 的连接时刻取决于主机端扫描。

## 调整前（2026-10-02）

| 阶段 | 结束时刻 | 耗时 |
|---|---|---|
| 引导程序加载并校验应用（约 5.4 MB） | 989 | 约 960 |
| PSRAM 初始化、代码与只读数据拷入 PSRAM、自检 | 1940 | 约 950，其中自检约 190 |
| 屏幕与触摸初始化 | 3478 | 约 1540 |
| BMI270 | 3885 | 约 410 |
| BQ27220 | 8276 | 约 4390 |
| 按键、BLE 初始化，开始广播 | 8496 | 约 220 |
| 主循环开始 | 8502 | |
| Bridge 连接 | 11008 | |
| 加密完成 | 11607 | |
| 收到对时 | 12094 | |

- BQ27220：驱动的 `bq27220_seal()` 无条件等待 `CONFIG_BQ27220_SEAL_SETTLE_MS`（2000 ms）。`bq27220_create()` 在校验电池配置后已封存一次，`bsp_battery_init()` 随后再次调用，合计约 4 秒。
- 白屏：CO5300 初始化序列把亮度寄存器 0x51 设为 0xFF 并发出 Display On，随后等待 600 ms；此时尚未写入任何一帧，面板显示上电后的帧存内容。
- 主循环在全部外设初始化之后才开始，旋转、渲染和 BLE 事件处理都排在其后。

## 调整

- 电量计在独立任务中初始化，就绪前电池图标隐藏，OTA 电源判定保持未就绪。封存等待本身未改动。
- CO5300 以零亮度启动，初始化序列不再包含 Display On 及其 600 ms 等待（`bsp_display_new()` 在设置方向后发出 Display On）；界面在首次刷新完成后经现有的亮度过渡淡入。板级改动记录在 `firmware/components/esp-mosaico-bsp/UPSTREAM.md`。
- BLE 在屏幕初始化后立即启动，其余外设初始化期间即可被连接；链路事件在队列中等待主循环。

## 调整后（2026-10-02）

| 里程碑 | 调整前 | 调整后 |
|---|---|---|
| 屏幕初始化完成 | 3382 | 2783 |
| 开始广播 | 8496 | 3196 |
| 主循环开始 | 8502 | 3778 |
| Bridge 连接 | 11008 | 4005 |
| 加密完成 | 11607 | 4574 |
| 收到对时 | 12094 | 5059 |
| BQ27220 就绪 | 8276 | 7901 |

应用通过 ESP-IDF v6.1 构建，按六段写入 ota_0 并全部通过设备哈希校验，未写入 NVS、分区表、引导程序或 OTA 数据。日志中没有新增的错误或告警。白屏是否消除、淡入是否正常、电池图标延后出现的观感，以及电量计与 IMU、触摸并发访问 I2C 的长期稳定性，尚待实机确认。

## 未处理

- 屏幕初始化中 Sleep Out 之后的 600 ms 等待；`esp_lcd_co5300` 的默认序列为 60 ms，未对照面板模组的上电时序规格。
- 应用启动前约 1.9 秒：引导程序校验应用、代码与只读数据拷入 PSRAM、PSRAM 自检（约 190 ms）。
- BMI270 初始化约 400 ms。
- Bridge 发现并连接设备的耗时在主机端。
