# QuotaFrame v1.1.0

本版新增 Waveshare RLCD 4.2 支持，并统一各设备在 Bridge 中的显示名称。

## 新增设备：Waveshare RLCD 4.2

ESP32-S3-RLCD-4.2 是第五款维护设备，使用 400×300 黑白反射式 LCD，无背光。

- **页面**：总览、Codex / Claude 详情、用量趋势、时钟和设置；详情页同时显示短周期与周周期。
- **操作**：KEY 上一页，BOOT 下一页，长按 KEY 进入设置。
- **用量趋势**：记录 48 个点，需要 FAT 格式的 microSD 卡。
- **连接**：与其他设备相同，支持加密 BLE 用量同步、时钟切换、滚轮翻页和固件 OTA。

## 变更

- 设备显示名称统一为硬件名称：M5StickS3、Waveshare AMOLED 2.16、ESP-Mosaico。设备升级固件后，Bridge 菜单显示新名称；BLE 广播名称和配对关系不变。

## 安装与升级

- **首次安装**：使用桌面版 Chrome 或 Edge 打开 [Web 烧录器](https://quotaframe.com/)，选择设备型号、连接 USB，按页面提示烧录，无需安装 ESP-IDF。
- **升级**：已有设备通过 Bridge 菜单升级固件，Bridge 自身按提示更新。
- **手动烧录**：Release 中的 `-full-` 镜像用于首次 USB 安装，`-ota-` 镜像用于 Bridge 升级，必须选择匹配设备型号的镜像。

完整步骤见[项目说明](https://github.com/eMUQI/QuotaFrame/blob/v1.1.0/README.zh-CN.md)。

SHA-256 用于检查完整性，不提供发布者签名认证。macOS 使用 ad-hoc 签名，尚无 Developer ID 签名或 notarization。
