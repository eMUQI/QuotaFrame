# QuotaFrame v1.3.0

本版支持在 QuotaFrame 上查看 Antigravity 的 Gemini 用量，并允许为每台设备单独选择显示组合。

## Gemini 与显示组合

- 设备默认同屏显示 **Codex + Claude**。也可以在 Bridge 中为每台设备选择 **Codex + Gemini** 或 **Claude + Gemini**。详情页会随组合切换，设备重连后会恢复已保存的选择。
- Gemini 数据来自 Antigravity 的 Gemini 模型组额度。请在电脑上安装 Antigravity CLI v1.1.11 或更新版本并登录。Bridge 会读取 5 小时和每周额度。若账号只提供周额度，设备只显示周额度。[Antigravity CLI 安装说明](https://antigravity.google/docs/getting-started?tab=cli)

## 安装与升级

- 使用新组合前，请同时更新 **Bridge** 和**设备固件**。连接设备后，在 Windows 托盘的设备子菜单或 macOS 菜单栏的对应设备菜单中选择「显示组合」。已连接的旧固件会提示「显示组合 · 需更新固件」。[显示组合设置](https://github.com/eMUQI/QuotaFrame/blob/main/bridge/README.md#gemini-与显示组合)
- 已安装 QuotaFrame 的设备可通过 Bridge 升级固件。首次安装请使用桌面版 Chrome 或 Edge，通过 Web 烧录器选择对应型号。[安装与升级说明](https://github.com/eMUQI/QuotaFrame/blob/main/README.zh-CN.md)
- macOS 安装包适用于 Apple Silicon，采用未公证的 ad-hoc 签名。[macOS 安装说明](https://github.com/eMUQI/QuotaFrame/blob/main/bridge/README.md#安装)
