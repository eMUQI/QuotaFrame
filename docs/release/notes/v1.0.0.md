# QuotaFrame v1.0.0

QuotaFrame 首次公开发布，源码、安装包与固件统一位于 `eMUQI/QuotaFrame`。QuotaFrame 将 Codex 和 Claude 用量同步到独立桌面屏。当前源码提供以下功能；发布前需完成[候选验收](../../validation/software-acceptance.md)，本文存在不代表该源码快照已经发布。

## 功能

- Windows 托盘与 Apple Silicon macOS 菜单栏 Bridge，通过 CodexBar / Win-CodexBar 读取用量。
- 四款维护设备：M5StickS3、Waveshare AMOLED 2.16、Waveshare ePaper 3.97、ESP-Mosaico。
- 加密 BLE 用量同步、显式添加设备、按设备管理连接与支持能力。
- 支持设备的时钟切换、滚轮翻页，以及经过桌面与设备确认的固件 OTA。
- 第三方设备可实现公开协议接入，无需加入官方型号表。

## 安装

Windows 提供安装器与便携 EXE，Apple Silicon macOS 提供 DMG。固件文件中 `-full-` 用于首次 USB 安装，`-ota-` 用于 Bridge 升级；必须选择匹配设备型号的镜像。完整步骤见[项目说明](../../../README.md)。

SHA-256 用于检查完整性，不提供发布者签名认证。macOS 使用 ad-hoc 签名，尚无 Developer ID 签名或 notarization。

## 验证边界

Windows 的四款设备基础功能和正常 OTA 已有开发设备测试覆盖，不能替代本次发布资产验收。macOS OTA、断电与回滚等故障路径、墨水屏长期残影和 SD 持久化仍需专项测试，详见[验证范围](../../verification.md)。
