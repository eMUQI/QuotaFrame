# QuotaFrame v1.2.1

本版修复 Windows 和 macOS 的用量同步问题，并改善 Waveshare AMOLED 2.16 的开机显示。

## 修复

- **Windows 和 macOS Bridge**：按 CodexBar 中的开关查询用量。Codex 和 Claude 各自同步，一路暂时取不到数据时，另一路仍可正常刷新。
- **Waveshare AMOLED 2.16**：等首帧画面准备好后再点亮屏幕，缓解开机时偶发的白闪。

## 安装与升级

- 用量同步修复随 **Bridge** 更新，AMOLED 2.16 的开机显示修复随**设备固件**更新。[安装与升级说明](https://github.com/eMUQI/QuotaFrame/blob/main/README.zh-CN.md)
- macOS 安装包适用于 Apple Silicon，采用未公证的 ad-hoc 签名。[macOS 安装说明](https://github.com/eMUQI/QuotaFrame/blob/main/bridge/README.md#安装)
