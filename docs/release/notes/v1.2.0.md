# QuotaFrame v1.2.0

本版新增 MindReset Read Pico 支持，ESP-Mosaico 增加实验性摄像头手势和 Type-C 免按键下载。

## 新增设备：MindReset Read Pico

Read Pico 是第六款维护设备，使用 684×1216 十六灰阶墨水屏。

- **页面**：主页同屏显示 Codex 与 Claude 的短周期和周周期用量、告警状态和 24 小时趋势；另有时钟、横屏主页和设置页。
- **操作**：KEY1 / KEY3 在主页与时钟间切换，KEY2 整屏刷新，长按 KEY2 进入设置；设置项直接点按屏幕选择。
- **显示**：支持四向自动旋转；用量达到 80% 和 95% 时分级提示。
- **用量趋势**：每 30 分钟记录一次，保留 48 个点，需要 FAT 格式的 microSD 卡，可在运行中插入。
- **时钟与电量**：内置 RTC 掉电保持时间，显示电量与充电状态。
- **连接**：与其他设备相同，支持加密 BLE 用量同步、时钟切换、滚轮翻页和固件 OTA。

## ESP-Mosaico

- **摄像头手势（实验性）**：在左槽安装 CameraBoard 后，于设置中打开 CAMERA 并保存。用量页挥手或左右招手切到下一页；OK 或点赞手势保持约半秒进入时钟，再次挥手唤醒。功能默认关闭。详见[手势指南](https://github.com/eMUQI/QuotaFrame/blob/v1.2.0/docs/validation/mosaico-gestures.md)。
- **Type-C 免按键下载**：安装本版后，设备正常运行时可由电脑通过 Type-C 直接进入下载模式，不再需要按住 BOOT 开机。首次安装和应用无法启动时仍使用 BOOT。
- **升级需要一次有线安装**：本版应用分区由 4 MiB 扩大到 7 MiB，旧版设备无法通过 Bridge 蓝牙升级，Bridge 中点击升级会提示设备拒绝该固件。请按[有线烧录步骤](https://github.com/eMUQI/QuotaFrame/blob/v1.2.0/docs/validation/mosaico-gestures.md#有线烧录)安装一次；配对关系、亮度和自动时钟设置会保留，之后的版本恢复蓝牙升级。

## 修复

- macOS：修复添加设备时偶发没有完成的问题。

## 安装与升级

- **首次安装**：使用桌面版 Chrome 或 Edge 打开 [Web 烧录器](https://quotaframe.com/)，选择设备型号、连接 USB，按页面提示烧录，无需安装 ESP-IDF。
- **升级**：已有设备通过 Bridge 菜单升级固件，Bridge 自身按提示更新。ESP-Mosaico 见上文。
- **手动烧录**：Release 中的 `-full-` 镜像用于首次 USB 安装，`-ota-` 镜像用于 Bridge 升级，必须选择匹配设备型号的镜像。

完整步骤见[项目说明](https://github.com/eMUQI/QuotaFrame/blob/v1.2.0/README.zh-CN.md)。

SHA-256 用于检查完整性，不提供发布者签名认证。macOS 使用 ad-hoc 签名，尚无 Developer ID 签名或 notarization。
